# D2 starter

A minimal TypeScript/Vite browser project with Deno checks and GitHub Pages deployment.

A simple drawing app. You can draw with markers, place emohi stickers, make your own stickers, undo and redo, and export your drawings as a PNG

## How to use it

- Choose between the thin or thick markers and drag it on the canvas to draw.
- Pick a sticker and click where on the canvas you want to place it.
- Type an emoji or small text in the custom sticker here box and click create sticker to create your own stickers.
- Undo and redo step through your marks. Each stroke or sticker used is a step.
- Redraw wipes the canvas pixels and rebuilds the picture from the saved.
- Clear wipes the canvas clean.
- Export saves your drawing as a png.
